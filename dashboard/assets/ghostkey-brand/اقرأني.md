# حزمة هوية غوستكي للموقع

## محتويات المجلدات

**svg** — ملفات متجهة لا تفقد جودتها مهما كبرت (الأفضل للموقع)
- `ghostkey-mark-purple.svg` الرمز بالبنفسجي، للخلفيات الفاتحة
- `ghostkey-mark-white.svg` الرمز بالأبيض، للخلفيات البنفسجية والداكنة
- `ghostkey-mark-plum.svg` الرمز بالبرقوقي الداكن
- `ghostkey-logo-horizontal-light.svg` الرمز مع الاسم، للخلفيات الفاتحة
- `ghostkey-logo-horizontal-dark.svg` الرمز مع الاسم، للخلفيات الداكنة
- `ghostkey-icon.svg` أيقونة مربعة (رأس الشبح على بنفسجي)
- `ghostkey-icon-head-purple.svg` رأس الشبح وحده بالبنفسجي

**png** — صور بخلفية شفافة بثلاثة مقاسات (٥١٢ و١٠٢٤ و٢٠٤٨) لكل لون، وأيقونة مربعة ١٠٢٤

**favicon** — أيقونة تبويب المتصفح وأيقونات الجوال، ارفعيها كلها في جذر الموقع

**social** — `og-image-1200x630.png` الصورة اللي تظهر لما أحد يشارك رابط موقعك

**brand.css** — درجات الألوان والخطوط جاهزة كمتغيرات

## انتبهي
الاسم «GHOSTKEY» في ملفي الشعار الأفقي نص حي يأخذ خط «سبيس غروتسك» من موقعك، فلازم يكون `brand.css` مربوطاً بالصفحة. إذا تبين صورة ثابتة للشعار مع الاسم، صدّريها من لوحة التصميم.

## الكود: داخل `<head>`

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#54266F">

<meta property="og:title" content="GhostKey — فخ سلسلة الإمداد">
<meta property="og:image" content="https://موقعك/og-image-1200x630.png">
<meta name="twitter:card" content="summary_large_image">

<link rel="stylesheet" href="/brand.css">
```

## الكود: الشعار في رأس الصفحة

```html
<!-- على خلفية فاتحة -->
<a href="/" class="gk-lockup gk-on-light" aria-label="غوستكي">
  <img src="/svg/ghostkey-mark-purple.svg" alt="">
  <span class="gk-divider"></span>
  <span class="gk-name">GHOSTKEY<span class="gk-tagline">فخ سلسلة الإمداد</span></span>
</a>

<!-- على خلفية بنفسجية: غيّري الصنف إلى gk-on-dark والصورة إلى ghostkey-mark-white.svg -->
```
